# Note

## Install binary

```sh
curl https://logdy.dev/install.sh | sh
sudo mv logdy /usr/local/bin/logdy
```

## Logdy Config

1. Klik Top Right Gear Icon
2. Klik "Export / import settings and columns"
3. Klik "Copy to clipboard"
4. Paste the clipboard to file, for example "logdy.json"
5. To load config use command:

`logdy --config logdy.json`
